Find an ECJ Class

Browse English, Communication Studies, and Journalism classes at Los Angeles Mission College. Find an open section, copy its five-digit Class Number, and use that number when you register.

Start With What You Need

Use Open Classes when you are looking for a section that may still have space. Switch to All Classes to see the full semester schedule, including wait-listed and closed sections.

Each course includes a short description to help you compare options. You can also filter by class format and textbook cost. ZTC means Zero Textbook Cost: all required textbooks and readings are free. Low Textbook Cost means required textbooks cost $50 or less. A ZTC class may use OER, library materials, or other free readings.

Class formats: In Person = meets on campus Online = asynchronous Zoom = scheduled live online meetings In Person Hybrid = campus + online Zoom Hybrid = campus + live Zoom HyFlex = choose campus or live online for scheduled meetings

Availability can change quickly, so use View Live Section Details before enrolling.

Ready to Register?

Each section shows a five-digit Class Number. That is the number you can copy and use to find the exact section in the LACCD Student Portal.

  1. Copy the Class Number from the section you want.
  2. Open the LACCD Student Portal and sign in.
  3. Choose Manage Classes, then Class Search and Enroll.
  4. Use the Class Number to locate the exact section, review the details, and complete enrollment.

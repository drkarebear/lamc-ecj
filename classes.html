ECJ Class Finder

Find an ECJ Class

Browse English, Communication Studies, and Journalism classes at Los Angeles Mission College. Find an open section, copy its five-digit Class Number, and use that number when you register.

Start With What You Need

Use Open ECJ Classes when you are looking for a section that may still have space. Switch to All ECJ Classes to see the full semester schedule, including wait-listed and closed sections.

Sections within each course display in order of when they start, with the earliest-starting section first.

Each course includes a short description to help you compare options. You can also filter by class format and textbook cost. ZTC means Zero Textbook Cost: all required textbooks and readings are free. Low Cost means required materials are available for a reduced price rather than free.

Class formats: In Person = meets on campus Online = no scheduled live meeting time listed Zoom = scheduled live online meetings In Person Hybrid = campus + online work Zoom Hybrid = online work + scheduled live Zoom meetings

Availability can change quickly, so use Section Details before enrolling.

Ready to Register?

Each section shows a five-digit Class Number. That is the number you can copy and use to find the exact section in the LACCD Student Portal.

  1. Copy the Class Number from the section you want.
  2. Open the LACCD Student Portal and sign in.
  3. Choose Manage Classes, then Class Search and Enroll.
  4. Use the Class Number to locate the exact section, review the details, and complete enrollment.
